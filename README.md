# Samarth Birajdar &mdash; Personal Portfolio

A production-quality personal portfolio website for **Samarth Birajdar**, inspired by the visual quality, clean layouts, typography, spacing, and polished user experience of modern SaaS products like [Steps AI](https://stepsai.co).

## Core Highlights

- **Visual Architecture**: Premium SaaS dark mode aesthetic featuring deep charcoal surfaces (`#07080c`), subtle radial glows, refined rim borders, and clean typography.
- **Frontend & Systems Focus**: Highlighting React.js, Next.js, TypeScript, and Python for Frontend Developer, SDE, and Full Stack roles.
- **Interactive Project Previews**:
  - **SaveIQ**: Interactive personal finance dashboard with income/expense tracking, budget limits, savings goals with forecasts, and local rule-based AI Coach.
  - **Attendance & Location Tracking System**: Interactive employee check-in preview, GPS geo-fence simulation, dual Admin & Employee self-service modules, and relational MySQL architecture.
- **Dedicated GitHub Integration**: Live GitHub public API synchronization with fallback to verified repositories.
- **Experience Timeline**: Verified internships at STQC (Government of India) and iKawn Inc.
- **Milestones & Certifications**: 175+ LeetCode solved (50-Day Badge) and certifications from GeeksforGeeks, Infosys, Apna College, and HackerRank.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI Library**: React 19 & TypeScript
- **Styling**: Tailwind CSS with custom SaaS tokens
- **Icons**: Lucide React
- **Animations**: CSS Compositor Transforms & Micro-interactions

## Getting Started

### Prerequisites

- Node.js 20.9 or higher
- npm

### Installation & Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the live portfolio.

### Production Build

```bash
# Build optimized static production bundle
npm run build

# Start production server
npm start
```
